# Docs

Kurze Uebersicht der Dokumente fuer den MusicEngineEditor.

## Inhalt
- MusicEngine_Syntax.md: Syntax und Ablauf fuer MusicEngine Scripts (.csx)
- Status.md: Aktueller Stand des Editors und der Engine-Anbindung

## Ziel
Diese Docs sind fuer Git (README im Docs Ordner) und sollen neuen Leuten schnell zeigen,
wie der Editor gerade arbeitet, wie die Engine gestartet wird und wie ein Script aussieht.

## Hinweis
Die Engine ist ein separates Repo. Sie wird vom Editor nur gestartet und mit einfachen
Text-Commands gesteuert. Details stehen in `Docs/Status.md`.
